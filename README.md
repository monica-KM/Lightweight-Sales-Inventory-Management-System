# Lightweight-Sales-Inventory-Management-System
轻量级销售开单与库存管理系统是一套面向中小型企业日常销售业务设计的 Web 管理系统，主要解决传统手工开单、历史单据查询不便以及库存信息分散等问题。系统支持客户信息维护、商品管理、销售单创建与编辑、价格计算、历史销售单查询、库存数量管理以及销售单打印与导出等功能，并可按照日期、客户名称、经办人等条件快速检索历史记录。系统采用前后端分离的设计思路，将业务数据集中存储和管理，在保证操作流程简洁的同时，提高销售开单、数据查询和库存管理效率。项目重点围绕实际业务需求进行功能设计，开发完成需求拆解、代码实现、问题调试与功能迭代。
# 轻量级销售开单与库存管理系统

一个用于个人作品展示的本地 Web Demo。项目采用 **Python 标准库 + SQLite + 原生 HTML/CSS/JavaScript**，不依赖第三方 Python 包，下载后即可在本地运行。

> 隐私说明：本仓库为脱敏重构版本。所有名称、客户、经办人、联系方式、地址、商品和单据数据均为虚构示例，不包含真实企业名称、商标或业务数据。

## 功能

- 销售开单：客户、经办人、发货方式、摘要、商品明细
- 三档价格：原价 / 折后价 / 建议零售价
- 库存联动：保存订单自动扣减库存
- 历史销售单：按日期、客户名称、经办人组合搜索
- 作废回库：作废销售单后自动恢复库存
- 基础资料：商品、客户、经办人管理
- 销售单打印：浏览器打印或“保存为 PDF”
- Windows 双击启动：`start_windows.bat` 使用 `pythonw` 后台运行，不保留命令行窗口

## 运行环境

- Python 3.10+
- Windows 10/11、macOS 或 Linux
- Chrome / Edge 等现代浏览器

## Windows 推荐运行方式

1. 安装 Python，并勾选 **Add Python to PATH**。
2. 解压项目。
3. 双击 `start_windows.bat`。
4. 浏览器会自动打开 `http://127.0.0.1:8765`。
5. 需要停止服务时双击 `stop_windows.bat`。

## 命令行运行

```bash
python app.py --open-browser
```

项目首次启动时会自动创建 `data.db`，并写入少量虚构演示数据。

## 核心数据表

- `products`：商品、规格、三档价格、库存
- `customers`：客户基础资料
- `handlers`：经办人
- `orders`：销售单主表
- `order_items`：销售单明细

## 关键实现

### 1. 库存与订单一致性
创建订单时使用 SQLite 事务：先校验全部商品库存，再写入销售单与明细，最后统一扣减库存；任一步骤发生异常均回滚，避免出现“订单已保存但库存未同步”的状态。

### 2. 作废自动回库
销售单作废时读取原明细，根据数量回补商品库存，并将订单状态改为“作废”，避免直接删除历史记录。

### 3. 历史组合搜索
支持日期区间、客户名称、经办人多个条件同时查询，文本条件使用模糊匹配。

### 4. 打印适配
销售单使用独立打印样式，关键信息区采用固定双列布局，并对 A4 横向打印做媒体查询，减少浏览器打印后字段换行和版式收缩问题。
